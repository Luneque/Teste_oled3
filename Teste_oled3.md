# Medidor de intensidade de Wi-Fi

Criar um projeto Arduino/ESP8266 para a placa **WEMOS D1 Mini (ESP8266EX)** com o **Wemos OLED Shield (SSD1306 64x48 I2C)**.

Conectar o D1 Mini à rede wi-fi S729-1 com senha 25102026.
Verificar a intensidade do sinal wi-fi dessa rede usando RSSI. 
Exibir no display um gráfico com a variação da intensidade do sinal no tempo. 

A renderização gráfica deve usar a biblioteca gráfica `U8g2`.
